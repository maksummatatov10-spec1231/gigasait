# Импорт реальных товаров (этап 2)

Скрипт `import_wb.py` качает 500 реальных товаров с Wildberries — с картинками,
описанием, характеристиками, ценами и рейтингом — и раскладывает их по папкам.

## Как запустить (на своём компьютере, нужен только Python 3)

```bash
# из корня проекта (Windows: python вместо python3, либо двойной клик по tools\import_wb.bat)
python3 tools/import_wb.py
```

Займёт ~10–15 минут: поиск WB ограничивает частоту запросов, поэтому скрипт специально
делает паузу ~2,5 с между поисками (иначе прилетает `429 Too Many Requests`). Если лимит
всё же сработал — скрипт сам подождёт и повторит, это не ошибка. Скрипт можно прерывать
(Ctrl+C) и запускать заново — уже скачанные товары пропускаются, недостающие добираются.

В конце каждой категории печатается сводка, например `{'ok': 25, 'skip': 0, 'nocard': 3, 'noimg': 0}`:
`ok` — скачано сейчас, `skip` — было скачано раньше, `nocard` — у товара нет карточки на CDN
(бывает у свежих/удалённых товаров, скрипт просто берёт следующий), `noimg` — не удалось скачать картинки.

Полезные варианты:
```bash
python3 tools/import_wb.py --limit 2        # быстрая проверка: по 2 товара на подкатегорию
python3 tools/import_wb.py --cat food       # только одна категория
python3 tools/import_wb.py --build-only     # только пересобрать products.js из папок
```

## Что получится

```
marketplace/products/
  electronics/
    449117282/            ← папка одного товара (id как на Wildberries)
      1.webp 2.webp 3.webp   картинки
      product.json           все данные (название, бренд, цена, описание, характеристики, ссылка)
      описание.txt           то же самое в удобном для чтения виде
  food/
  ...
marketplace/js/products.js   ← общий каталог для сайта (собирается автоматически)
```

После импорта просто открой `index.html` — сайт сам увидит `products.js` и покажет реальные товары
вместо заглушек. Страны (RU/KZ/BY/UZ/KG) распределяются равномерно — по 100 товаров на страну.

## Настройка

`import_config.json`:
- `per_category` — товаров на категорию (25 × 20 категорий = 500);
- `max_images` — картинок на товар (3);
- `image_size` — размер картинки на CDN (`c246x328`, `c516x688`, `big`);
- `categories` — категория сайта → подкатегория → поисковый запрос на WB. Меняй запросы как хочешь.

## Как это работает внутри

1. `search.wb.ru` — поиск популярных товаров по запросу (с троттлингом и повторами при 429).
2. `basket-NN.wbbasket.ru/.../card.json` — описание и характеристики. Номер «корзины» NN зависит
   от артикула (vol = id // 100000); таблица границ зашита в скрипт, а для новых диапазонов корзина
   ищется перебором соседних номеров и запоминается в `tools/.basket_cache.json`.
3. Те же корзины отдают картинки `images/c516x688/N.webp`.

## Почему только Wildberries?

У WB есть открытые JSON-эндпоинты (`search.wb.ru`, `card.json`, CDN с картинками), которые
отдают данные без авторизации. Ozon и Яндекс Маркет закрыты антибот-защитой (капча, подписи запросов),
надёжно их автоматически скачать нельзя. Структура `product.json` универсальная — при желании
товары с других площадок можно добавить вручную такой же папкой.
