# ⚡ GIGASAIT — мега мульти сайт

Учебный проект: главное меню → **Маркетплейс** / **Игры** / **Сообщество**.
Чистый HTML + CSS + JavaScript, без сборки и сервера.

## Как открыть
Открой `index.html` в браузере (двойной клик) — или распакуй последний архив из папки `release/`.

## Структура
```
index.html          главное меню (хаб)
assets/             стили и скрипты хаба
marketplace/        маркетплейс (SPA на hash-роутинге)
  js/data.js        страны, категории, генератор товаров-заглушек
  js/i18n.js        переводы интерфейса (RU/EN)
  js/featured.js    20 витринных товаров с реальными фото и описаниями
  img/categories/   фото категорий, img/products/ фото витринных товаров
  js/app.js         вся логика: каталог, поиск, корзина, избранное, заказы, настройки
games/, community/  заглушки разделов (следующие этапы)
release/            zip-архивы версий сайта
tools/              build_release.sh — сборка zip-релиза
                    import_wb.py + import_config.json — импорт реальных товаров с Wildberries
marketplace/products/  папки товаров (картинки + product.json), появляются после импорта
```

## Этапы
1. ✅ Основной сайт + маркетплейс (300 заглушек + 20 витринных товаров с реальными фото)
2. 🔧 Реальные товары — импортёр готов: `python3 tools/import_wb.py` (см. `tools/README.md`)
3. ⏳ Полировка: 30 языков, игры, сообщество

## Сборка релиза
```
./tools/build_release.sh 0.1.0
```
