# ⚡ GIGASAIT — мега мульти сайт

Учебный проект: главное меню → **Маркетплейс** / **Игры** / **Сообщество**.
Чистый HTML + CSS + JavaScript, без сборки и сервера.

## Как открыть
Открой `index.html` в браузере (двойной клик) — или распакуй последний архив из папки `release/`.

## Структура
```
index.html          главное меню (хаб)
assets/             стили и скрипты хаба
  js/theme.js       тема (единый источник истины giga.theme, плавная смена, color-scheme/theme-color) — общий для всех разделов
  js/device.js      определение устройства (телефон / планшет / ПК) → классы на <html>, общий для всех разделов
marketplace/        маркетплейс (SPA на hash-роутинге)
  css/parts/*.css   стили, разбитые по разделам (base, header, cards, catalog, product, cart, …, mobile — мобильная версия)
  js/data.js        страны, категории, генератор товаров-заглушек
  js/i18n.js        ядро переводов (автоопределение языка браузера, склонения, форматы)
  js/lang/*.js      15 словарей: ru, en, uk, be, kk, ky, uz, pl, de, fr, es, it, tr, zh, ar (RTL)
  js/products.js    485 реальных товаров (генерируется импортёром)
  js/translate.js   машинный перевод описаний на лету (Google Переводчик, кэш в localStorage)
  js/featured.js    20 витринных товаров с реальными фото и описаниями
  img/categories/   фото категорий, img/products/ фото витринных товаров
  js/core/          ядро: namespace, data, store, state, utils, theme, router, events, init
  js/ui/            общие элементы: toast, card, modal, lightbox, header, search
  js/views/         страницы: home, catalog, product, cart, favorites, compare, checkout, orders, settings, pages
  js/features/      функции: cart (корзина/избранное/сравнение), translate-dom, move-grid (перемещение карточек), motion (анимации)
                    модули подключаются обычными <script> по порядку зависимостей и общаются через window.APP
games/, community/  заглушки разделов (следующие этапы)
release/            zip-архивы версий сайта
tools/              build_release.sh — сборка zip-релиза
                    make_thumbs.py — миниатюры thumb.webp для карточек (в 5 раз меньше трафика)
                    import_all.py + import_config.json — импорт реальных товаров (Wildberries, Яндекс Маркет, Ozon)
marketplace/products/  485 реальных товаров: папка на товар (фото + product.json + описание.txt)
                    split_products.py — нарезка каталога на zip по 24 МБ
```

## Как устроен код (v0.8.0)
Без сборщика: каждый файл — самостоятельный модуль `(function(){ const A = window.APP; … Object.assign(A, {…}); })()`.
Порядок подключения в `marketplace/index.html` = порядок зависимостей. Новый модуль: создать файл в `js/views/` (или
`js/features/`), взять нужные функции из `A`, экспортировать свои через `Object.assign(A, …)`, добавить `<script>`.
Стили — по одному файлу на раздел в `marketplace/css/parts/`; мобильная вёрстка — в `mobile.css` через класс `html.is-mobile`.
