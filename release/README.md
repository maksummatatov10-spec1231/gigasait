# Релизы

Здесь лежат zip-архивы всех версий сайта: `gigasait-vX.Y.Z.zip`.
Внутри — папка `gigasait/`, открывать `gigasait/index.html` в браузере.

Собрать новый архив: `./tools/build_release.sh X.Y.Z` (Linux/macOS/Git Bash).

Начиная с v0.5.0 все фото товаров хранятся в формате WebP (≤1000px), поэтому архив с 485 товарами
весит ~57 МБ и помещается в лимит GitHub (100 МБ на файл).
Те же архивы прикреплены к релизам: https://github.com/maksummatatov10-spec1231/gigasait/releases
